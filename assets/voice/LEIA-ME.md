# Voz gravada do locutor

Coloque aqui arquivos **.mp3** com estes nomes e liste os nomes (sem `.mp3`) em `voices.json`,
por exemplo `["luta", "round1", "nocaute"]`. O jogo usa a gravação sempre que ela existe e a voz do
aparelho (escolhida em Opções → LOCUTOR) para o resto.

| Arquivo | Fala |
|---|---|
| `round1.mp3` … `round4.mp3` | "Round 1" … "Round 4" |
| `round-final.mp3` | "Round final" |
| `luta.mp3` | "Luta!" |
| `nocaute.mp3` | "Levou uma pisa!" (o K.O.) |
| `tempo.mp3` | "Tempo!" |
| `empate.mp3` | "Empate!" |
| `venceu-hotmonster.mp3`, `venceu-flash.mp3`, `venceu-genildo.mp3`, `venceu-anderon.mp3`, `venceu-hgl.mp3` | "<nome> venceu!" |
| `super-hotmonster.mp3` | "Chuva de ração!" |
| `super-genildo.mp3` | "Tolerância zero!" |
| `super-anderon.mp3` | "Ligando pra casada!" |
| `super-hgl.mp3` | "Chave de fenda!" |
| `vs-<lutador1>-<lutador2>.mp3` | "<lutador 1> contra <lutador 2>!" (opcional) |
